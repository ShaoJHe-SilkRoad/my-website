Sectorium

Load to work. Unload to pause. Disconnect to unplug.

Sectorium manages file-based development volumes such as DEV_APFS. Your external drive stays one physical drive; its development volume is shown underneath it. AUV includes Sectorium — no separate app download.

Mac 0.17.7: the basic Load → Unload → Load and Disconnect cycle has been confirmed on the developer’s Mac and external DEV_APFS volume. Sectorium is unchanged since 0.17.2, where that cycle was confirmed. Windows 0.16.3 has the interface only; its storage actions are unavailable.

Use an existing development volume

  1. Connect the external drive, open AUV → Sectorium, and find its card. External drives appear above internal storage.
  2. If your existing volume is not registered, use Register existing volume, or the drive’s menu → Register existing… to choose its image. Registration keeps your existing files in place.
  3. Choose Load. Enter an unlock password if prompted, then wait for Loaded before opening your development work.

Register once. Switching between AUV and Sectorium keeps the registration and last observed state; it does not require starting over.

Choose the right action

ActionWhat happens
LoadMounts the development volume so you can use its files.
UnloadUnmounts only the development volume. The physical drive remains connected and available. When it finishes, Load is available again.
DisconnectUnloads the related volumes and safely ejects the whole external drive. Wait for the success message before unplugging.

Save work before Unload or Disconnect. If an application is using the volume, follow the displayed prompt to close it and retry. An incomplete operation is not permission to unplug. Internal storage cannot be physically disconnected through Sectorium.

Reconnect and keep the status current

Connect the drive again and use Load when its registered volume appears. Per-volume automatic loading can be enabled in its settings.

Sectorium listens for macOS disk appearance, disappearance and property changes. It also performs a consistency check every five minutes and runs deeper checks when something changes. Returning to the tab does not restart a full check; Refresh remains available when you need it.

Create a new volume

Create volume lets you choose a drive, name and logical capacity for a file-based APFS image without repartitioning the physical disk. Logical capacity is a maximum, not space reserved immediately. Creation and encryption still need broader real-device validation; try them only with backed-up, noncritical data.

If a step does not finish

Read the message shown and expand History and diagnostics on the volume card. Use the offered retry or return-to-development action after resolving it. If the disk has been unplugged, reconnect it before loading; registering the same image again is not a repair.

Privacy and validation scope

Sectorium observes disk identity, mount state and supported whole-drive I/O statistics. It does not scan project file contents. Unknown statistics stay unknown; they do not mean zero activity.

The confirmed lifecycle applies to the developer’s current Mac and external volume. It does not establish reliability for every drive, encrypted image, new-volume creation or recovery scenario. Mac 0.17.7 includes Apple silicon and Intel code for macOS 14+, but physical Intel hardware and macOS 14/15 have not been tested. See the installation guide for the compatibility checks.

分区工

加载后开发，卸载后暂停，安全断开后拔盘。

分区工管理 DEV_APFS 这类文件型开发卷。外接硬盘仍是一块物理硬盘，开发卷显示在它下面。分区工已包含在 AUV 中，无需另下一个应用。

Mac 0.17.7：加载、卸载、重新加载和安全断开流程，已在开发者当前的 Mac 与外接 DEV_APFS 开发卷上确认可用。分区工自 0.17.2 起未改动，上述流程在 0.17.2 已经确认。Windows 0.16.3 仅提供界面，磁盘操作尚不可用。

使用已有开发卷

  1. 连接外接硬盘，打开 AUV → 分区工，找到对应硬盘卡片。外接硬盘优先于内置盘显示。
  2. 尚未登记时，点击登记已有开发卷，或从硬盘菜单选择登记已有开发卷…并选中镜像。登记会保留原有文件。
  3. 点击 Load（加载）；如提示解锁，输入密码。显示已加载后再打开开发工作。

只需登记一次。在 AUV 与分区工之间切换会保留登记信息和最近状态，不必重新登记。

三个操作有什么区别

操作作用
Load · 加载挂载开发卷，使其中的文件可以使用。
Unload · 卸载开发卷只卸载开发卷，母盘仍连接电脑、保持可用。完成后可再次点击加载。
Disconnect · 安全断开硬盘卸载相关卷并安全弹出整个外接硬盘。看到成功提示后再拔线。

卸载或断开前先保存工作。若有应用占用开发卷，按界面提示退出该应用后重试。操作未完成不代表可以拔盘；分区工不会物理弹出内置系统盘。

重新连接与状态更新

重新连接硬盘后，已登记的开发卷会再次显示，点击加载即可继续使用。也可在开发卷设置中启用连接后自动加载。

分区工监听 macOS 的磁盘出现、消失和属性变化通知，每五分钟再进行一次一致性检查；发现变化时深入核验。切回页面不会重新等待完整检查，需要时仍可点击刷新。

新建开发卷

创建开发卷可选择硬盘、名称和逻辑容量，创建文件型 APFS 镜像，不重新划分物理分区。逻辑容量是上限，不是立即预留的空间。创建与加密仍需更多实盘验证，请先在已备份、非关键数据环境中试用。

操作没有完成时

查看页面提示，并展开开发卷卡片上的历史与诊断。解决后再使用界面提供的重试或返回开发操作。硬盘已拔出时，先重新连接再加载；重复登记同一镜像不能修复操作失败。

隐私与验证范围

分区工读取设备身份、挂载状态及可用的整盘 I/O 统计，不扫描项目文件内容。统计不可用时显示未知，不会当作零活动。

已确认的基础流程仅对应开发者当前的 Mac 和外接开发卷，不代表所有硬盘、加密镜像、新建和故障恢复场景均已验证。Mac 0.17.7 面向 macOS 14+，包含 Apple silicon 和 Intel 代码，但尚未测试实体 Intel Mac 或 macOS 14/15。兼容性检查范围见安装指南。
