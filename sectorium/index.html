Sectorium

A virtual development disk on your drive — without repartitioning it.

Sectorium creates or uses a file-based APFS disk image, such as DEV_APFS, and helps you start it, stop it and safely eject its external drive. It is part of AUV; there is no separate app to download.

Early-stage feature. Back up important data and try it with noncritical data first. Unexpected disconnection or interrupted operations can cause data loss. Unplug only after the complete safe-eject operation succeeds.

Read the drive list

External drives appear first. Each physical drive groups its volumes and any verified virtual development disk beneath it. A 300 GB development disk on a 1 TB external drive is not a second piece of hardware.

Select the intended drive and check its name, capacity and development disk. Internal system-drive details are secondary; Sectorium does not physically eject the internal drive.

First-time setup

  1. Install AUV, then open Sectorium in the top navigation.
  2. Select your drive and open Settings. If tools are missing, use Install HESectorium. If an existing installation is reported as conflicting, check its diagnostics before proceeding.
  3. Already have a development image? Choose Adopt existing disk and select it. Wait for verification. Do not create another DEV_APFS just to use the one you have.
  4. Need a new one? Choose Create development disk, select its location and logical capacity, then create it. The default is 100 GiB; this is a maximum size, not space reserved immediately. Encryption and case sensitivity are optional. Keep an encryption password safe: losing it can prevent access.
  5. Start after creation is off by default. Use Start when you want to use the disk, and wait for it to be ready.

Installing tools and creating a disk are different steps. Neither operation formats or repartitions your physical drive. Existing images are not meant to be overwritten.

Everyday use

What you wantWhat to use
Open a stopped development diskStart, then wait for readiness; unlock it if prompted.
Close the virtual disk, leaving the hardware connectedStop.
Unplug an external driveSave work and close apps using it, then choose Safe Eject for the whole drive. Unplug only after full completion.
Check a changed connection or an errorRefresh, then read the current state and diagnostics.

Busy, unknown or partly complete does not mean safe to unplug. If an operation fails, read the failed step, resolve the reported problem and use the offered recovery action. Do not force-unmount, kill processes, delete lock files or repeatedly press Resume.

Automatic mounting

Settings shows your automation preference and the service’s observed state separately. Turning on the preference does not by itself start the service or mount the disk. The current installer does not activate the background service automatically. If the service is not loaded or its state is unknown, use manual Start; automatic mounting is not confirmed.

Privacy and current limits

Sectorium reads device identity, mount status and supported I/O statistics. It does not scan your project file contents. Read/write rates describe the physical drive, not an individual project; unavailable figures show as unknown.

For 0.15.1, real-device creation, mounting, stopping, ejection and service activation have not been tested. Encryption, disconnect recovery, sleep and restart behavior also remain unverified. Software tests do not establish that these operations are safe on your hardware. The detailed test record is linked below.

分区工

在硬盘上使用虚拟开发盘，不必重新分区。

分区工创建或使用 DEV_APFS 这类文件型 APFS 镜像，帮助你启动、停止开发盘，以及安全弹出所在的外接硬盘。它包含在 AUV 中，无需另下一个应用。

仍处于早期开发阶段。 请先备份重要数据，用非关键数据试用。意外断连或操作中断可能导致数据损失；完整安全弹出成功前不要拔盘。

看懂硬盘列表

外接硬盘优先显示，每块物理硬盘下会列出它的卷和已核实的虚拟开发盘。1 TB 外接硬盘上的 300 GB 开发盘，不是第二块硬件。

选择目标硬盘，核对名称、容量和开发盘。内置系统盘的信息放在次要位置，分区工不会物理弹出内置硬盘。

首次设置

  1. 安装 AUV，从顶部进入 Sectorium。
  2. 选择硬盘，打开 Settings（设置）。缺少工具时使用 Install HESectorium（安装 HESectorium）；若提示已有安装冲突，先查看诊断。
  3. 已有开发镜像时，选择 Adopt existing disk（接纳已有开发盘）并选中它，等待核验。不要为了使用现有 DEV_APFS 再创建一个。
  4. 需要新建时，选择 Create development disk（创建开发盘），设置位置和逻辑容量。默认 100 GiB，表示容量上限，不是立即占用这么多空间。加密和大小写敏感均为可选项；请妥善保管加密密码，丢失后可能无法访问。
  5. Start after creation（创建后启动）默认关闭。需要使用时点击 Start（启动），等待就绪。

安装工具与创建开发盘是不同操作，两者都不会格式化或重新分区物理硬盘。不要覆盖已有镜像。

日常怎么用

你想做什么使用哪个操作
打开未启动的开发盘启动，等待就绪；提示解锁时输入密码。
只关闭虚拟盘，硬盘仍留在电脑上停止。

忙碌、未知或部分完成，都不表示可以拔盘。 操作失败时，先看失败步骤，解决提示的问题，再使用界面提供的恢复操作。不要强制卸载、杀进程、删除锁文件或反复点击恢复。

自动挂载

设置中分别显示自动挂载偏好和服务的实际状态。勾选偏好本身不会启动服务，也不等于已经挂载；当前安装器不会自动启用后台服务。服务未加载或状态未知时，请手动点击启动，不要认为自动挂载已经可用。

隐私与当前限制

分区工读取设备身份、挂载状态和可用的 I/O 统计，不扫描项目文件内容。读写速率属于整块物理硬盘，不是单个项目；取不到的数值显示为未知。
