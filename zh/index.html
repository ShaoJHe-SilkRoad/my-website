AUV

Agent Usage Viewer

一眼看清 AI 编程还剩多少额度。

AUV 是一款 Mac 与 Windows 桌面应用，随时显示 Codex 与 Claude 的用量和限额，帮你安排工作节奏。它还包含线程工（ThreadOS），为编码智能体团队准备指令；在 Mac 上还有分区工（Sectorium），用来管理开发盘。

  • English / 中文

AUV 适用于 Mac 与 Windows 电脑。请在电脑上打开本页下载。

项目背后的想法+
用来做什么
一个应用，查看账户用量、准备团队指令、管理 Mac 开发卷。
最难的部分
Claude 的精确用量来自已登录的 Safari 会话，所以 Safari 被隐藏、最小化或在另一个桌面时，AUV 也要能继续读取。另一半工作，是在发布签名、公证的 Mac 通用版的同时，维护一个独立的 Windows 版。
需要帮手的地方
Windows 是短板：它还停在 0.16.3，没有签名，也缺少 Sectorium 的磁盘操作。最能帮上忙的，是一位熟悉 Windows 打包与代码签名的开发者。也同样欢迎每天使用 Codex 或 Claude 的人提供测试和设计反馈。

QDigest

读懂研究

看见研究，也读懂研究。

用英文与简体中文解释有据可查的健康研究：邮件简报用于发现，网页提供更完整的研究解释。

每篇解读都注明原始论文（期刊、DOI、PubMed 编号），并说明是否仅依据摘要。仅供学习阅读，不构成医疗建议。
