Windows 0.18.6

Windows 11 · x64 · portable ZIP · unsigned — build 20261111.1.

  1. Download for Windows · v0.18.6. Choose the application ZIP, not GitHub's source archive.
  2. Right-click the ZIP in File Explorer → Extract All. Keep the complete extracted folder, including every DLL and runtime file.
  3. Run AUV.exe from that folder as your normal Windows user. Confirm AUV 0.18.6 in Properties → Details → Product version. This build has no separate About dialog.
  4. Choose AUV or Sectorium in the top bar. ThreadOS opens from Codex’s settings (ThreadOS → Open). In Settings → Desktop Wizard, enable the Desktop Wizard; it floats separately above applications. The AUV tray icon opens the usage/CPU/RAM popup (Windows may put it in the tray overflow; drag it beside the clock to pin it. Settings → System Tray → clear “Show the AUV icon in the system tray” to hide it completely).
  5. Optional, for Claude: on the Claude page choose Connect Claude and confirm. Choose Load in Chrome or Load in Edge: AUV copies the path of BrowserCompanion\extension in the AUV folder and opens the extensions page. Turn on Developer mode, choose Load unpacked and paste the path. Then choose Open claude.ai and sign in there yourself. The checklist ticks itself. Keep AUV in a folder you can write to, not under Program Files. Browser companion guide.
  6. Use Quit in the tray or Ctrl+Shift+Q to exit completely. Closing the main window can keep the tray running.

The .NET 10.0.12 desktop runtime is included; the portable app does not require a separate .NET SDK/runtime installation. Optional WorkBuddy connection additionally needs Microsoft Edge WebView2 Runtime, which is not bundled. Codex data requires the installed Codex client and its existing login. No new provider login is required simply to open AUV.

This Windows build is not digitally signed and may trigger Windows or organization security controls. Check the official package checksum; keep protections enabled and report the exact message if blocked. No warning-free or clean-machine certification is claimed.

Upgrade: quit the old copy, extract the new package into a separate folder and run its AUV.exe. Preserve %LOCALAPPDATA%\AUV.Windows.UI.Preview: it contains settings.v1.json and the separate workbuddy-web-* browser profile. The preview-era directory name is intentionally retained; 0.18.5, 0.18.4 and 0.16.x settings are read unchanged. The browser companion stays in BrowserCompanion\ inside the AUV folder, so after moving to a new AUV folder, load the extension from there once; AUV shows the step again. Coming from 0.18.5, AUV offers to delete its old copy. Do not delete settings or assume rollback compatibility. Mac preferences are separate.

New in 0.18.6: Claude on Windows. The AUV Browser Companion for Chrome or Edge reads Claude’s 5-hour and weekly limits from claude.ai’s Usage page, in English or Chinese; your sign-in stays in the browser. One Connect Claude button sets it up, and a three-step checklist ticks itself. Claude’s bars now use the same green and red as Codex. The app has a cleaner look with restrained motion, which turns off with Windows “Show animations”; the quota bars and the Desktop Wizard look as before. Settings from 0.18.5, 0.18.4 and 0.16.x carry over. Full release notes.

Scope: Codex read-only usage is connected; WorkBuddy Credit sync is experimental. Claude’s 5-hour and weekly limits come from claude.ai through the browser companion, loaded in Developer mode (not from a browser store). Claude Code’s local estimate and Antigravity have no reading on Windows. Missing/stale/disconnected quotas are hidden; verified zero stays visible. ThreadOS generates and copies instructions without dispatching work or applying settings. Sectorium is UI only with storage actions disabled. ARM64, installer, signing reputation, receiving-client execution and Windows storage qualification are not included.

macOS 0.18.4

macOS 14 or later · Apple silicon or Intel — one Universal download, build 2026110607. Developer ID signed and Apple notarized.

Install or update

  1. Download AUV_Mac_0.18.4_Universal.zip. Choose the app ZIP, not GitHub’s source archive.
  2. If AUV is already running, choose Quit from its menu. Closing the window may leave it running in the menu bar.
  3. Double-click the ZIP. Drag UMA.app into Applications on your Mac’s internal disk, replacing the old app when updating. The app opens as AUV; UMA.app is its retained filename. Keep your existing settings and development images.
  4. Open the copy in Applications and follow the normal macOS first-open prompt. Check AUV 0.18.4 at the bottom left of its main window.
  5. To see Codex account usage, install and sign in to the Codex app on the same Mac, then choose Codex in AUV and refresh. A ChatGPT browser login alone is not enough.

What is included

  • AUV: account usage in the main window, menu bar and desktop floating view. Available information depends on the connected provider.
  • ThreadOS: prepare model and thinking-level instructions for your coding team, then copy them to your Leader. ThreadOS guide.
  • Sectorium: load a Mac development volume, unload it while keeping the drive connected, or disconnect the entire external drive. Sectorium guide and current progress.

New in 0.18.4: Claude’s automatic refresh recovers by itself when Safari’s companion goes quiet, a read that gets no answer is retried within seconds, and Claude no longer shows Unavailable between syncs. If AUV needs Safari opened or restarted, it asks first. ThreadOS moved into Codex’s settings. 0.18.4 kept Accuracy Sync working with Safari on another desktop or minimized; 0.18.0 redesigned the main window and Settings.

If something is missing

  • No Codex usage: confirm Codex is signed in and usable on this Mac, update Codex if needed, then refresh AUV. If usage is still unavailable, report your macOS, Codex and AUV versions with the message shown; do not send account credentials.
  • An older AUV opens: quit it and open the replacement in Applications.
  • macOS blocks the app or reports damage: download the official ZIP again and compare the checksum below. Keep system security enabled. Report a problem if it persists.
Compatibility checks and current limits

The build targets macOS 14 and later on Apple silicon (arm64) and Intel (x86_64). It was checked on an Apple silicon Mac running macOS 27.2, including an Intel-code startup check through Rosetta. A physical Intel Mac and macOS 14/15 have not been tested. This is not a claim that every Mac, Codex account or external drive has been verified.

The basic Sectorium load, unload, reload and disconnect cycle has been confirmed on the developer’s Mac and external DEV_APFS volume. New-volume creation, encryption and other hardware still need separate real-device testing.

Windows 0.18.6

Windows 11 · x64 · 便携 ZIP · 未签名，构建号 20261111.1。

  1. 下载 Windows 版 · v0.18.6。请选择应用 ZIP，不要选 GitHub 的源码压缩包。
  2. 在文件资源管理器右键 ZIP → 全部解压。保留完整文件夹，包含所有 DLL 和运行时文件。
  3. 以普通用户运行其中的 AUV.exe，在 AUV.exe 文件属性 → 详细信息确认产品版本 0.18.6。本版没有单独的“关于”窗口。
  4. 在顶部切换 AUV 与分区工；线程工从 Codex 设置中的 ThreadOS（线程工）→ 打开 进入。在设置 → 桌面浮窗中启用 Desktop Wizard 桌面浮窗，它独立悬浮于应用上方。AUV 托盘图标可展开用量与 CPU/内存；图标可能位于托盘折叠菜单，可自行拖到时钟旁固定；在设置 → 系统托盘中取消“在系统托盘中显示 AUV 图标”可隐藏图标。
  5. 可选（Claude）：在 Claude 页面选择“连接 Claude”并确认。选择“在 Chrome 中加载”或“在 Edge 中加载”：AUV 会复制 AUV 文件夹中 BrowserCompanion\extension 的路径并打开扩展页。开启开发者模式，选择加载已解压的扩展程序并粘贴该路径。再选择“打开 claude.ai”，由你自己登录。清单会自动打勾。请把 AUV 放在可写的文件夹中，不要放在 Program Files 下。浏览器伴侣使用说明。
  6. 用托盘 Quit 或 Ctrl+Shift+Q 完全退出；只关闭主窗口可能仍保留托盘。

已包含 .NET 10.0.12 桌面运行时，便携包无需另外安装 .NET SDK/运行时。可选 WorkBuddy 连接另需 Microsoft Edge WebView2 Runtime，本包不附带。Codex 需已安装的客户端及其现有登录；仅打开 AUV 无需新增代理登录。

Windows 包未进行数字签名，可能受到 Windows 或组织安全策略拦截。请核对官方文件校验值，保持安全防护开启；若受阻，请反馈具体提示。不承诺无安全提示，也不宣称通过干净机器认证。

升级：先正常退出旧版，将新包全部解压到独立文件夹，再运行新版 AUV.exe。保留 %LOCALAPPDATA%\AUV.Windows.UI.Preview，其中含 settings.v1.json 及独立的 workbuddy-web-* 浏览器配置。为延续设置，本版保留预览时期的目录名，0.18.5、0.18.4 和 0.16.x 的设置原样沿用。浏览器伴侣留在 AUV 文件夹中的 BrowserCompanion\，换用新的 AUV 文件夹后需从那里再加载一次扩展，AUV 会重新显示这一步；从 0.18.5 升级时，AUV 会询问是否删除旧副本。不要删除设置，也不保证回退兼容。Mac 偏好单独保存。

0.18.6 新功能：Windows 版可以读取 Claude 了。Chrome 或 Edge 中的 AUV 浏览器伴侣从 claude.ai 用量页读取 Claude 的 5 小时与每周额度，支持英文或中文界面，登录状态留在浏览器中。一个“连接 Claude”按钮完成设置，三步清单会自动打勾。Claude 额度条与 Codex 使用相同的绿色和红色。界面更整洁，动效克制，Windows 关闭“显示动画”时随之关闭；额度条和桌面浮窗外观不变。0.18.5、0.18.4 和 0.16.x 的设置都会沿用。完整更新说明。

范围：Codex 只读用量已接入；WorkBuddy Credit 同步为试验功能。Claude 的 5 小时与每周额度由浏览器伴侣从 claude.ai 读取，扩展以开发者模式加载（未上架浏览器商店）。Claude Code 本地估算和 Antigravity 在 Windows 上没有读数。不可用、过期或断开的额度隐藏，已确认的零仍显示。线程工生成、复制指令，不代发任务或应用设置。分区工仅为界面，磁盘操作禁用。ARM64、安装器、签名信誉、接收端执行与 Windows 存储认证不在本版范围内。

macOS 0.18.4

macOS 14 或更新版本 · Apple silicon 或 Intel，共用一个通用安装包，构建号 2026110607。已使用 Developer ID 签名并通过 Apple 公证。

安装或更新

  1. 下载 AUV_Mac_0.18.4_Universal.zip。请选择应用 ZIP，不要选 GitHub 的源码包。
  2. 如果 AUV 正在运行，先从应用菜单选择退出；只关窗口可能仍会在菜单栏运行。
  3. 双击 ZIP 解压，将 UMA.app 拖入 Mac 内置盘的“应用程序”文件夹；更新时替换旧应用。打开后显示为 AUV，UMA.app 是沿用的文件名。保留已有设置和开发镜像。
  4. 打开“应用程序”中的新版，按 macOS 正常首次启动提示操作。在主窗口左下角确认 AUV 0.18.4。
  5. 要查看 Codex 账户用量，请在同一台 Mac 安装并登录 Codex 应用，再回到 AUV 选择 Codex 并刷新。只登录 ChatGPT 网页不够。

里面有什么

  • AUV：在主窗口、菜单栏和桌面浮窗查看账户用量；可显示的信息取决于已连接的服务。
  • 线程工：为开发团队准备模型与思考档位指令，再复制给 Leader。线程工指南。
  • 分区工：加载 Mac 开发卷；仅卸载开发卷、保留母盘连接；或安全断开整个外接硬盘。分区工指南与当前进展。

0.18.4 的变化：Safari 伴侣失去响应时，Claude 的自动刷新能自行恢复；没有回应的读取几秒内就会重试；两次同步之间，Claude 不再显示 Unavailable。需要打开或重启 Safari 时，AUV 会先询问。线程工移到了 Codex 的设置中。0.18.4 让 Safari 在另一个桌面或最小化时也能精确同步；0.18.0 重新设计了主窗口与设置。

遇到问题

  • 没有 Codex 用量：确认本机 Codex 已登录且可用，必要时更新 Codex，再刷新 AUV。仍不可用时，请附上 macOS、Codex 和 AUV 版本及页面提示反馈；不要发送账户凭据。
  • 打开的还是旧版：退出后，从“应用程序”打开刚替换的新版。
  • macOS 阻止启动或提示损坏：重新下载正式 ZIP，核对下方校验值，保持系统安全防护开启。仍有问题时请反馈。
兼容性检查与当前范围

本包面向 macOS 14 及以上的 Apple silicon（arm64）和 Intel（x86_64）Mac。实际检查在运行 macOS 27.2 的 Apple silicon Mac 上完成，包括通过 Rosetta 启动 Intel 代码。尚未在实体 Intel Mac、macOS 14/15 上测试；不代表所有 Mac、Codex 账户或外接硬盘均已验证。

分区工的加载、卸载、重新加载与安全断开流程，已在开发者当前的 Mac 和外接 DEV_APFS 开发卷上确认可用。新建开发卷、加密和其他硬件仍需单独进行实盘验证。
