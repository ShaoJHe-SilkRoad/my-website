ThreadOS

Choose once. Copy once. Your Leader handles the bound team.

ThreadOS is the team-settings workspace inside AUV — Agent Usage Viewer, formerly UMA. It prepares a deterministic instruction for your existing native agents. It does not host another agent engine or automatically send tasks.

When to use it

Set the model and reasoning effort of Leader, Coder Cluster, Reviewer Cluster and QA separately. Paste the instruction into the Leader responsible for your development folder. AUV never chooses a project, recipient thread or filesystem root.

How to set the team

  1. Open the ThreadOS tab.
  2. Choose a model and Thinking effort in each of the four rows.
  3. Read the exact instruction preview, then select Generate and Copy.
  4. Paste once into your intended Leader conversation. The receiving Leader verifies its managed folder/team binding and submits supported native parameters.
  5. Read its requested, submitted and effective-observed results separately. A manual native Model/Thinking selection may still be required for the receiving Leader itself.

Ultra, with an honest capability boundary

The existing Thinking menu retains Low, Medium, High and Ex High and adds Ultra. Version 0.15.1 uses the versioned sol-luna-ultra-20261010.1 catalog and read-only local Codex CLI model metadata. Its five Sol/Astra/Terra entries allow ultra; GPT-6 Luna does not. This is client-specific capability evidence, not proof about every account or the receiving desktop client. Stale, missing or offline metadata is shown as unverified; deterministic requests remain possible for catalog-supported combinations. A known unsupported combination is blocked without changing your prior selection. Ultra may increase usage and delegate additional agents on eligible hosts. Copying does not run Ultra or change a service tier.

What counts as applied?

Selection → generated/copied instruction → receiving validation → native submission → verified effective state are separate steps. A local parser receipt with pending_native_selection and unknown effective state is not an application ACK. Old versioned TOSCFG requests retain their original catalogs and replay rules; the current compact set_team_models instruction stays target-free.

Troubleshooting and limits

If Copy fails, keep your selections and retry the clipboard action. If a saved value is unsupported, correct that role explicitly; defaults do not replace it. If the receiving host rejects a model or lacks a control, it must report the exact restriction and keep the request unchanged. Never treat a prompt, label or successful send as backend proof. Optional Factorium organizes implementation/review roles where configured; it is not required to use the copy workflow.

Compatibility and references

AUV 0.15.1 requires macOS 14 or newer; the downloadable build targets Apple silicon. Native host capabilities and configured role bindings remain prerequisites for actual model selection. Codex model/list capabilities · Reasoning configuration · Maintained manual.

ThreadOS（线程工）

选择一次，复制一次，由接收 Leader 设置自己的团队。

ThreadOS 是 AUV — Agent Usage Viewer（原名 UMA）内的团队设置工作台。它为现有原生代理生成确定的设置指令，不另建代理引擎，也不自动发送任务。

适合做什么

分别设置 Leader、Coder Cluster、Reviewer Cluster 和 QA 的模型与思考档位。将指令粘贴给负责你的开发文件夹的 Leader。AUV 不选择项目、接收线程或文件系统根目录。

操作步骤

  1. 打开顶部 ThreadOS（线程工）。
  2. 分别选择四个角色的模型和思考档位。
  3. 查看精确指令预览，点击“生成并复制指令”。
  4. 粘贴给目标 Leader 一次。接收 Leader 核实自己的开发根与团队绑定，再提交受支持的原生参数。
  5. 分别看请求值、已提交值和已验证生效值。接收 Leader 自身仍可能需要用户在原生 Model/Thinking 控件手动选择。

Ultra 的能力边界

原菜单保留低、中、高、极高，新增 Ultra。0.15.1 使用 sol-luna-ultra-20261010.1 版本化目录和只读的本地 Codex CLI 模型元数据。目录中五个 Sol/Astra/Terra 型号允许 ultra，GPT-6 Luna 不允许。这是特定客户端的能力依据，不代表所有账户或接收端桌面应用均支持。离线、缺失或过期元数据标为待核实；目录支持的组合仍可确定地生成请求。已知不支持的组合会被阻止，原选择保留。Ultra 可能增加用量并委派额外代理；复制不会执行模型或改变服务档位。

怎样判断真正完成

当前选择 → 已生成/复制 → 接收端核验 → 原生提交 → 已验证生效，是不同状态。pending_native_selection、effective unknown 的解析回执不是执行成功 ACK。旧版 TOSCFG 按原目录与重放规则继续兼容；当前 set_team_models 指令没有目标项目。

排错与限制

复制失败时保留选择，重试剪贴板动作。旧保存值不受支持时，明确纠正对应角色，默认值不会覆盖它。宿主拒绝模型或缺少控制时，应报告具体限制，不静默替换。消息发送成功、提示词或界面标签都不证明后端生效。Factorium 是可选的实现/审查角色组织方式，不是使用复制流程的前提。

兼容范围与资料

AUV 0.15.1 要求 macOS 14 或更新；下载构建面向 Apple silicon。真正设置仍依赖原生宿主能力和有效角色绑定。Codex model/list 能力 · 思考档位说明 · 持续维护的手册。
